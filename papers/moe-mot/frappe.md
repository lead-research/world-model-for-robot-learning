## FRAPPE: Infusing World Modeling into Generalist Policies via Multiple Future Representation Alignment [arXiv 2026]
- **链接**: [arXiv:2602.17259](https://arxiv.org/abs/2602.17259)
- **分类**: MoE/MoT-style
- **核心问题**: 现有VLA的世界建模方法存在两个根本问题：(1) 像素级重建目标迫使模型过度关注冗余像素而非语义信息，限制OOD泛化；(2) 推理时依赖预测的未来观测导致误差累积。如何在不生成像素、不增加推理复杂度的前提下，为VLA注入鲁棒的世界建模能力？
- **核心方法**: FRAPPE（Future Representation Alignment via Parallel Progressive Expansion）采用两阶段微调策略。Mid-training阶段：模型学习预测未来观测的潜态表征（而非像素）；Post-training阶段：通过并行扩展计算量，同时与多个不同视觉基础模型（VFM）的表征空间对齐。推理时保持相同计算图，不使用VFM。
- **主要特点**:
  - **多VFM表征对齐**：不依赖单一视觉模型的归纳偏置，而是同时与多个预训练VFM（如SigLIP、DINO、CLIP等）对齐，获得更鲁棒的隐式世界模型
  - **Mixture-of-Prefix-and-LoRA (MiPA)**：并行扩展多个输入流，每个专家共享冻结backbone但拥有独立可学习token和LoRA模块，最终通过可学习路由聚合动作
  - **两阶段渐进训练**：Mid-training全参数微调适应世界建模目标；Post-training并行扩展实现计算缩放。避免直接并行训练导致的慢收敛
  - **无需动作标注数据**：可利用人类操作视频（无动作标注）进行训练，大幅降低数据成本
  - **推理零开销**：训练时VFM参与对齐，推理时完全丢弃VFM，保持原计算图
- **与现有方法对比**:
  - vs UWM/UVA/PAD（显式像素生成）：这些方法直接生成未来像素，导致计算浪费在冗余外观上，且OOD生成质量差。FRAPPE完全避免像素生成
  - vs FLARE/VPP（单表征隐式对齐）：FLARE对齐单一VLM的未来嵌入，存在归纳偏置。FRAPPE通过多VFM对齐消除单一表征的局限
  - vs Genie/Dreamitate（视频模型作为编码器）：这些工作需要视频扩散模型参与推理。FRAPPE训练时使用VFM，推理时丢弃，计算效率更高
  - vs RDT/RDT2（纯动作扩散）：无世界建模能力，易过拟合动作历史。FRAPPE在保持扩散策略优势的同时注入世界知识
- **关键洞察**: 世界建模的本质不是"看见未来"，而是"理解动态"。像素是未来观测的最冗余表示；单一VFM的嵌入是次优表示；多VFM共识才是最鲁棒的动态理解。FRAPPE的核心设计哲学是"用多样性对抗不确定性"——多个视觉基础模型从不同角度（语义、几何、纹理）编码场景，它们的共识表征自然过滤掉与动态无关的噪声。
- **技术细节**:
  - **基座模型**: 基于RDT（Robotic Diffusion Transformer），一个用于双臂操作的扩散Transformer基础模型
  - **Mid-training阶段**:
    - 从多个VFM中蒸馏出一个教师编码器
    - 全参数微调RDT，使其输出能预测未来观测的潜态表征
    - 损失函数：$\mathcal{L}_{\text{action}} + \lambda \mathcal{L}_{\text{align}}$，对齐损失为预测表征与教师编码器输出之间的MSE
  - **Post-training阶段（MiPA）**:
    - 扩展为N个并行输入流（N个"专家"）
    - 每个专家：独立可学习的前缀token + 独立LoRA模块
    - 冻结原始backbone参数，仅训练前缀、LoRA和路由器
    - 每个专家的未来前缀由不同VFM的嵌入监督
    - 路由机制：可学习路由器聚合各专家输出的动作
  - **训练数据来源**:
    - 遥操作数据（有动作标注）：用于动作监督
    - 人类手部操作视频（无动作标注）：用于世界建模对齐
    - 互联网级第一人称视频：可扩展为持续预训练
  - **推理阶段**: 丢弃所有VFM，保留MiPA架构的多流前向传播，获得缩放优势但无额外外部依赖
- **实验结果深度分析**:
  - **Benchmark**: RoboTwin（仿真）、真实世界任务
  - **性能**: 超越SOTA方法，在长程和未见场景中展现强泛化
  - **数据效率**: 当遥操作数据极度稀缺时，利用人类操作视频可获得10-15%的性能提升（对比纯遥操作基线）
  - **两阶段训练的有效性**: 从论文描述推断，直接并行扩展训练收敛慢，两阶段设计是关键实现细节
  - **多VFM对齐的增益**: 虽未给出具体消融数字，但论文明确将多VFM对齐作为核心贡献，其优势体现在OOD泛化和长程稳定性上
- **存在的不足/局限性**:
  - MiPA的路由机制复杂度：N个专家+路由器增加了推理计算量，虽然低于视频生成模型，但仍高于单流策略
  - 多VFM的选择是启发式的（哪些VFM组合最优？），缺乏系统性分析
  - Mid-training的全参数微调对大型基础模型（如RDT-1B+）而言计算成本高昂
  - 人类视频到机器人策略的迁移依赖未来表征的embodiment-agnostic性质，但未给出理论分析
- **与已有知识的关联**: 
  - 与LDA-1B形成鲜明对照：两者都避免像素级预测，但LDA-1B选择DINO潜空间进行显式动力学预测，FRAPPE选择多VFM对齐实现隐式世界建模。这是"统一潜空间"vs"多表征共识"的路线之争
  - 与DiT4DiT共享"避免重建像素"哲学，但DiT4DiT从视频DiT的中间特征提取条件，FRAPPE从多VFM对齐获得隐式知识
  - 与RDT/RDT2直接继承关系：FRAPPE是在RDT基础上的增强，而非从头设计
- **开放问题/局限性**:
  - **表征共识的理论基础**：多VFM对齐为何比单一VFM更鲁棒？是否存在最优的VFM组合？如果VFM之间存在冲突表征，模型如何仲裁？
  - **LoRA+前缀的容量限制**：MiPA冻结backbone仅训练LoRA，在多大程度上限制了世界建模知识的注入？全参数微调是否会有更大收益？
  - **路由器的可解释性**：路由器如何分配权重？是否某些专家主导特定类型任务？这关系到MoE结构在机器人策略中的适用性
  - **长程任务中的误差累积**：虽然避免了显式像素预测的误差累积，但隐式表征对齐是否也存在类似的表征漂移？
- **对研究工作的启示**:
  - **长程任务**: FRAPPE的两阶段训练+多VFM对齐特别适合长程任务。Mid-training让模型建立动态理解，Post-training通过并行计算增强稳定性。对于家庭长程任务（如整理房间），隐式世界建模比显式像素预测更实用
  - **泛化性/家庭场景**: 家庭场景的核心优势——人类视频极易获取。FRAPPE证明无动作标注的人类视频可直接用于世界建模训练，这意味着家庭机器人可以从YouTube/TikTok视频中学习物理常识，无需昂贵的遥操作
  - **直接可试**: 
    - MiPA（前缀+LoRA+路由器）架构可直接应用于实验室的RDT或任何DiT策略，作为轻量级增强模块
    - 多VFM对齐可以立即尝试：使用SigLIP+DINO+CLIP组合对齐实验室现有策略的未来预测
    - 两阶段训练策略可作为通用recipe：先全参数适应新目标，再并行扩展精炼
  - **与实验室工作关联**: dli目前关注VLA长程操作，FRAPPE提供了"不增加推理负担注入世界知识"的精确方案。其数据效率结论（人类视频替代遥操作）对降低数据采集成本有直接指导意义
