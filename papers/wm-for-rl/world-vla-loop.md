# World-VLA-Loop: Closed-Loop Learning of Video World Model and VLA Policy

- **Venue**: arXiv'26.02
- **arXiv**: [2602.06508](https://arxiv.org/abs/2602.06508)
- **Code**: [GitHub](https://github.com/showlab/World-VLA-Loop)
- **Project**: [https://showlab.github.io/World-VLA-Loop/](https://showlab.github.io/World-VLA-Loop/)
- **Category**: World Model for RL

## Core Problem
How to build closed-loop co-evolution of world model and VLA policy, while solving world model's imprecise action following and missing reward signals?

## Core Method
World-VLA-Loop — three designs: (1) SANS dataset mixes success and near-success trajectories to improve action-outcome alignment, (2) state-aware video world model jointly predicts future frames and binary rewards, (3) closed-loop co-evolution — world model for VLA post-training, improved policy rollouts feed back to fine-tune world model.

## Key Characteristics
- SANS dataset: specially mixes success and near-success trajectories, improving action-outcome alignment
- State-aware world model: jointly predicts frames and rewards, coupling reward estimation to generator
- Closed-loop co-evolution: alternating improvement of world model and VLA
- Reduced physical interaction dependency: significantly lowers real-world interaction cost

## Key Insight
World model and VLA's "chicken and egg" problem: good world model needs good policy rollout data, good policy needs good world model training. World-VLA-Loop's solution is closed-loop — let both start from initial state, alternately improve, gradually enhance.

## Technical Details
- **Architecture**: SANS data + state-aware world model (frame + reward joint prediction) + VLA policy + closed-loop updates
- **SANS**: Success trajectories + near-success trajectories (near-success failures) mixed, improving action following
- **State-aware world model**: Simultaneously predicts future frames and binary rewards from diffusion latent variables
- **Closed-loop**: World model trains VLA → VLA rollout data improves world model → repeat
- **Key design**: Rewards coupled to generator, not independent module

## Experimental Results
- Simulation and real robots: significant VLA performance improvement
- Reduced physical interaction: significantly lowers real interaction cost
- Ablations: SANS, state-aware world model, closed-loop all contribute to performance

## Limitations
- Closed-loop convergence: does it guarantee convergence to optimal?
- SANS data collection: requires manual annotation of near-success trajectories
- State-aware world model reward prediction accuracy
- Multi-round iteration time cost

## Connection to Prior Work
- Shares "co-evolution/iterative improvement" framework with WoVR, VLAW
- SANS concept (learning from failures) related to self-supervised learning
- Related to state-aware video generation (e.g., JEPA-VLA)

## Implications for Our Research
- **Long-horizon**: Closed-loop co-evolution particularly important for long-horizon tasks — long-horizon tasks have stronger interdependence between world model and policy, requiring multiple rounds to synergize.
- **Home scenes**: Near-success trajectories in home scenes (e.g., almost grabbed but not quite) are very abundant, SANS concept can fully utilize these valuable data.
- **Directly testable**: World-VLA-Loop components are clear: SANS dataset + state-aware world model + closed-loop. Can be implemented step by step in lab. Near-success trajectories can be generated by random perturbations of current policy.
